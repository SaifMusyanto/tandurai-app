Cara kerja singkat Sensor membaca suhu & kelembapan kumbung → gateway mengirimnya tiap 10 detik lewat Wi-Fi ke server Tandurai (MQTT terenkripsi, port 8883) → pemilik farm melihat data dan mengatur sprayer, kipas, dan exhaust dari dashboard. Jadwal dan aturan otomatis disimpan di gateway, sehingga tetap berjalan walau internet putus.

1Sebelum berangkat

Sebagian besar instalasi yang gagal berasal dari data unit atau perlengkapan yang tertinggal. Cek semuanya di kantor.

Data unit (per gateway)

  • File setup <hwUid>.json dari menu Registrasi Perangkat (berisi hwUid dan deviceSecret)
  • Label perangkat: UID gateway + kode klaim (mis. K7Q2-M9XD) sudah tertempel di kotak
  • Firmware terpasang esp32-gw/0.3.2 (terlihat di OLED saat menyala)
  • Unit sudah diuji nyala di kantor: OLED tampil, relay bunyi klik saat diuji

Perlengkapan

  • Obeng (+/−), tang potong & kupas, tespen / multimeter
  • Kabel listrik, terminal, isolasi, cable tie, sekrup & fischer
  • Kabel sensor RS485 (2 inti sinyal + 2 inti daya) secukupnya
  • HP dengan hotspot (cadangan) & kuota data
  • Laptop + kabel USB-C data (bila perlu upload ulang firmware)
  • Lampu uji / beban kecil untuk mengetes relay

Koordinasi dengan pemilik farm (H-1)

  • Pemilik sudah punya akun dashboard Tandurai, sudah login sekali, dan farm sudah dibuat
  • Kumbung yang akan dipasangi sudah ditambahkan di menu Operasional Kumbung
  • Nama & password Wi-Fi lokasi (harus 2,4 GHz) sudah diminta
  • Pemilik (atau orang yang bisa login ke akunnya) hadir saat instalasi untuk langkah klaim (Bab 6)
  • Diketahui alat apa saja yang akan dikendalikan: sprayer/pompa, kipas, exhaust
Jaga kerahasiaan device secret deviceSecret adalah kunci login gateway ke server dan hanya muncul sekali saat registrasi. Jangan dikirim lewat grup chat, jangan difoto, dan jangan ditempel di label. Bila hilang, unit harus didaftarkan ulang dengan hwUid baru.

2Survei lokasi

Tentukan posisi gateway dan sensor sebelum mengebor apa pun.

Cek sinyal Wi-Fi di titik pemasangan

  1. Berdiri di titik calon gateway, sambungkan HP ke Wi-Fi lokasi.Gateway hanya bisa memakai Wi-Fi 2,4 GHz. Router dual-band biasanya punya dua nama (mis. Kumbung dan Kumbung_5G); pakai yang bukan 5G.
  2. Buka satu halaman web atau kirim pesan.Pastikan internet benar-benar jalan, bukan hanya tersambung ke router.
  3. Lihat bar sinyal.Minimal 2 dari 4 bar. Bila lemah, geser posisi gateway mendekati router atau minta pemilik memasang repeater.
  4. Catat keamanan Wi-Fi.Bila router diset WPA3 saja, minta diubah ke WPA2 atau WPA2/WPA3.

Pilih posisi

KomponenSyarat posisi
Kotak gatewayDi luar ruang tanam atau di sudut yang tidak terkena semprotan kabut/air langsung. Mudah dijangkau untuk melihat OLED dan saklar. Dekat stop kontak 220 V yang tidak ikut padam bersama beban.
Sensor RS485Di dalam kumbung, setinggi rak tengah, tidak tepat di depan nozzle sprayer, kipas, atau pintu. Terlindung dari tetesan air. Kabel ke gateway sebaiknya < 50 m.
Kabel beban 220 VDipisahkan jalurnya dari kabel sensor dan dijauhkan dari board ESP32/antena.
Posisi sensor menentukan kualitas data Sensor yang terkena semprotan langsung akan membaca kelembapan 100% terus-menerus, dan aturan otomatis jadi tidak berguna. Data ini juga dipakai untuk perkiraan panen AI.

3Pemasangan fisik

Keselamatan listrik — wajib
  • Semua penyambungan dilakukan dengan MCB/stop kontak dalam keadaan mati. Cek dengan tespen.
  • Kontak relay maksimal 10 A 250 VAC (relay SRD-05VDC-SL-C). Pompa atau beban lebih besar wajib memakai kontaktor.
  • Beban disambung ke terminal COM dan NO (normally open) — bukan NC — supaya beban mati saat gateway mati.

3.1 Kotak gateway

  1. Pasang kotak di dinding.OLED menghadap depan dan lubang kabel di bawah, agar air tidak masuk.
  2. Sambungkan kabel daya 220 V ke input catu daya.Saklar power dalam posisi OFF.

3.2 Sensor RS485 (suhu & kelembapan)

Sensor RS-O2WS-N01 memakai 4 kabel. Warna di bawah adalah warna umum pabrikan; selalu cocokkan dengan label pada kabel sensor.

Kabel sensorFungsiSambung ke terminal gateway
CoklatDaya + (12 V DC)+12V
HitamDaya − (GND)GND
KuningRS485 AA (485+)
BiruRS485 BB (485−)
Setelan sensor jangan diubah Gateway membaca sensor di alamat Modbus 1 dengan kecepatan 4800 baud (bawaan pabrik). Bila A/B tertukar, sensor tidak terbaca tetapi tidak rusak — cukup tukar kedua kabel itu.

3.3 Aktuator (relay)

ChannelLabel OLEDUntukBatas nyala sekali jalan
A1WtrSprayer / pompa air2 menit
A2FanKipas sirkulasi60 menit
A3ExhExhaust60 menit

Batas nyala adalah pengaman di firmware: walau ada perintah atau aturan yang salah, relay mati sendiri setelah batas itu. Karena itu pompa/sprayer harus di channel A1; bila dipasang di A2/A3 pompa bisa menyala sampai 1 jam.

Motor pompa/kipas bisa mengganggu gateway Saat relay memutus motor, muncul lonjakan listrik yang dapat membuat gateway offline sesaat. Pasang peredam (snubber RC atau MOV) paralel dengan motor bila tersedia, dan lakukan uji di Bab 7.

4Menyalakan & mengisi setup

Unit baru (atau yang memorinya dikosongkan) otomatis membuka mode setup saat pertama menyala. Pengisian dilakukan dari HP.

  1. Nyalakan saklar power.OLED menampilkan Tandurai Gateway · Memulai... · esp32-gw/0.3.2, lalu MODE SETUP dengan nama Wi-Fi setup.
  2. Di HP, buka Wi-Fi dan sambungkan ke Tandurai-Setup-XXXX.Tanpa password. Bila HP memperingatkan "tidak ada internet", pilih tetap tersambung.
  3. Buka browser ke http://192.168.4.1.Muncul halaman Setup Gateway Tandurai.
  4. Isi formulir sesuai tabel di bawah.Lalu tekan Simpan & restart.
  5. Tunggu ±30 detik.Gateway restart dan mencoba tersambung. Lanjut ke Bab 5 untuk membaca hasilnya.

Slide sensor RS485

Muncul hanya bila sensor terbaca. Nilai wajar kumbung jamur: suhu 22–30 °C, kelembapan 75–95 %RH, O₂ ±20,9 %. O₂ hanya ditampilkan di OLED, tidak dikirim ke dashboard.

Slide ini tidak muncul? Sensor tidak menjawab: cek daya 12 V dan kabel A/B (Bab 3.2).

Status lampu dan versi firmware LED merah pada board = power (selalu menyala). Versi firmware tampil sebentar di layar pertama saat menyala — pastikan esp32-gw/0.3.2.

Lanjut ke Bab 6 hanya bila WiFi dan MQTT keduanya terhubung dan slide RS485 muncul.

6Klaim di dashboard

Klaim menghubungkan gateway ke farm milik pemilik. Dilakukan dari akun pemilik farm, setelah gateway MQTT terhubung (agar daftar sensor & aktuator sudah dilaporkan).

  1. Login ke dashboard Tandurai dengan akun pemilik farm.Pastikan farm yang benar sedang aktif.
  2. Buka menu Devices → klik Tambah gateway.
  3. Isi UID gateway dan Kode klaim.Salin persis dari label perangkat, lalu lanjut.
  4. Beri nama gateway dan pilih Kumbung utama.Contoh nama: Gateway Kumbung A.
  5. Atur sensor dan aktuator.Beri nama yang jelas dan pilih kumbung masing-masing (atau Ikut kumbung utama). Contoh: Sensor Rak Tengah, Sprayer Kumbung A, Exhaust Belakang.
  6. Simpan / klaim.Gateway muncul di daftar Devices dengan status online.
Penamaan yang baik Pakai nama yang dipahami pekerja kumbung, sertakan lokasi: "Kipas Kumbung B Utara" lebih berguna daripada "A2". Nama bisa diubah kapan saja dari dashboard tanpa menyentuh alat.
Gagal klaim? Pastikan UID dan kode klaim diketik persis seperti label (huruf besar, tanda strip). Gateway yang sudah diklaim farm lain tidak bisa diklaim lagi — hubungi admin Tandurai.

7Uji fungsi

Lakukan semua uji di bawah sebelum serah terima. Catat hasilnya di Formulir (Lampiran D).

7.1 Data sensor

  • Menu Monitoring: suhu & kelembapan muncul dan berubah setiap ±10 detik
  • Nilai di dashboard sama dengan nilai di slide RS485 OLED
  • Tiup/pegang sensor sebentar: kelembapan/suhu ikut berubah

7.2 Relay — tanpa beban dulu

  1. Lepas beban dari relay.Bila perlu, ganti dengan lampu uji.
  2. Menu Automation Control: nyalakan A1 secara manual.Status berubah Mengirim… → berhasil; relay berbunyi klik; OLED menunjukkan Wtr:ON.
  3. Matikan lagi, lalu ulangi untuk A2 dan A3.Tempel label nama alat di setiap relay sesuai hasil uji.

7.3 Relay — dengan beban

  1. Sambungkan beban asli.Lakukan dengan listrik mati, lalu nyalakan kembali.
  2. Nyala-matikan setiap aktuator 3 kali.Perhatikan OLED selama pengujian.
  3. Gateway sempat offline / OLED menampilkan Memulai... saat relay berpindah?Itu gangguan listrik dari motor (Bab 3.3). Catat channel mana, pasang peredam, dan laporkan ke tim.

7.4 Aturan otomatis (bila diminta pemilik)

  • Buat satu aturan uji, mis. sprayer nyala bila kelembapan < 80 %, nyala 60 detik
  • Aktuator tidak lagi bertanda Pending sync (config sudah diterima gateway)
  • Matikan Wi-Fi sebentar: OLED WiFi putus, aturan tetap berjalan, lalu tersambung lagi sendiri dalam ±15 detik setelah Wi-Fi kembali
  • Hapus aturan uji bila tidak dipakai

8Serah terima

Instalasi dianggap selesai bila semua butir ini tercentang.

Teknis

  • OLED: WiFi & MQTT terhubung dengan Wi-Fi lokasi (bukan hotspot)
  • Gateway online di menu Devices, terklaim ke farm yang benar
  • Data sensor masuk di Monitoring
  • Semua relay lulus uji tanpa & dengan beban
  • Beban tersambung ke COM–NO; relay berlabel
  • Kotak tertutup rapat, kabel rapi & terikat

Edukasi pemilik

  • Cara melihat Monitoring dan menyalakan aktuator manual
  • Arti tampilan OLED (WiFi/MQTT/relay)
  • Cara restart: saklar OFF 2 detik → ON
  • Ganti Wi-Fi: mode setup lewat saklar 3× (Lampiran A)
  • Jangan memindah sensor ke depan sprayer/kipas
  • Nomor kontak tim Tandurai
Sebelum meninggalkan lokasi Hapus file <hwUid>.json dari HP/laptop pribadi bila tidak lagi diperlukan, dan pastikan tidak ada password Wi-Fi pemilik yang tertulis di kotak.

AMembuka mode setup lagi

Tombol board berada di dalam kotak, jadi mode setup dibuka dengan saklar power. Dipakai untuk mengganti Wi-Fi, hwUid, atau secret.

LangkahSaklarTungguOLED
1ON1–2 detik (sampai layar menyala)Memulai...
2OFF±2 detikmati
3ON1–2 detikSetup: 2/3
4OFF±2 detikmati
5ON—MODE SETUP
Aturan waktu
  • Setiap kali ON kurang dari 5 detik. Menyala lebih lama dianggap nyala normal dan hitungan kembali ke 0.
  • Setiap kali OFF beri jeda ±2 detik agar board benar-benar mati.
  • Listrik padam biasa tidak membuka mode setup; jadwal & aturan tetap berjalan.

Di halaman setup, kolom password dan secret yang dikosongkan tidak mengubah nilai tersimpan. Untuk ganti Wi-Fi saja, cukup isi SSID dan password baru lalu simpan.

Cara terakhir bila mode setup tetap tidak terbuka: upload ulang firmware lewat USB-C dengan opsi hapus memori (EraseFlash=all); seluruh setting kembali kosong.

CSensor LoRa (bila diaktifkan)

Sensor ZYD-M500CO2 (suhu, kelembapan, CO₂) terhubung tanpa kabel lewat LoRa. Di firmware 0.3.2 fitur ini dimatikan (USE_LORA false); bagian ini berlaku setelah tim software mengaktifkannya.
